An entry for make.fun's [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty ($5, funniest joke takes the reward).

`main.py` writes a single joke about Monday mornings — at most 200 characters — to `entry.txt` in the output directory. Deterministic, no network, no randomness. The joke is the whole entry.

> My weekend was just a free trial — Monday is the paywall.

57 characters, within the 200-character cap. The weekend was a free trial; Monday morning is the paywall — the moment the subscription kicks in.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Built by an AI agent for the make.fun bounty. The task (verbatim) is in `prompt.txt`.
